## 2. 候选产品叙事

- 产品定位：维护一个可追溯、许可边界清晰且具证据分级的 Web UI/UX 设计知识库，供其他项目的前端参考分析按 ID 消费。
- 目标用户：知识库维护者，以及在其他项目中进行前端参考分析的项目成员。
- 当前 Phase 候选目标：建立和执行来源登记、许可核验、知识抽取、证据分级和人工评审的收集闭环；维护首批来源和案例观察。
- 当前 Phase 候选非目标：不实现 Web 应用、组件库或运行时服务；不把知识记录写成下游项目的需求、接口或验收事实；不镜像第三方截图、设计稿、字体、图标或品牌资产。
