## 1. 深色工作台配方组（LUMEN B 套参照）

| 案例 | 观察到的配方 | 关键参数记录 |
|---|---|---|
| linear.app | 近黑画布 + 单一强调色纪律：薰衣草蓝 `#5e6ad2` 只用于品牌 / 焦点环 / 少量 CTA，从不装饰 | 画布 `#010102`；面板阶梯 `#0f1011/#141516/#18191a/#191a1b`；发丝线 `#23252a` |
| raycast | 状态色软底配方：饱和语义色一律配 15% 透明度软底，深底上保持区分度 | 画布 `#07080a`；表面阶梯 `#0d0d0d→#121212`；如 `rgba(89,212,153,0.15)` |
| sanity | 纯无彩中性阶 + 统一激活信号：灰阶无冷暖偏色；电光蓝 `#0052ef` 作全站唯一 hover/激活色 | 灰阶 `#0b0b0b→#212121→#353535→#797979→#b9b9b9→#ededed`；CTA 珊瑚红 `#f36458` 唯一暖点 |
| warp | 暖炭画布：深色不必蓝灰，暖近炭 `#2b2622` 也可作深色基底 | CTA 反白 `#f7f5f0`；发丝线 `#3f3a36` |

**组内共性（多案例一致，可支撑 C 级结构判断）**：深色系统普遍采用「1 个画布色 + 3–4 级表面阶梯 + 发丝线 + 单一强调色」结构；语义色靠提亮 + 软底维持区分度。
