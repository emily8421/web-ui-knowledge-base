# Case 观察：Ant Design v5 令牌体系与站点视觉配方

- **来源**：`SRC-DS-003`（https://ant.design，链接核验 2026-08-31 可访问）
- **证据等级**：**D**（单一来源观察，只作设计启发；关键种子值与 v5 官方默认主题一致，官方文档事实按来源上限 B 单独引用）
- **状态**：candidate（2026-08-31 登记，待评审）
- **观察输入**：Plan A：extract-tokens.py 静态抽取，访问日期 2026-08-31（dumi SSR 输出的完整 HTML + @layer antd 编译 CSS，含 7,798 个 `--ant-*` 令牌、329 种颜色字面量）
- **观察维度**：配色与表面分级 / 字阶与密度 / 圆角边框阴影 / 令牌架构

## 1. 观察到的配方

### 1.1 主交互色「四件套」：主色 / 悬停 / 激活 / 同色相软底

主色 `#1677ff`（站点 theme-color 与令牌一致，出现 143 次）；配套悬停 `#4096ff`、激活 `#0958d9`、**软底 `#e6f4ff`**（`colorPrimaryBg`，出现 72 次）。语义色的选中态、hover 态一律走「同色相浅软底」而非加深边框——浅色场景下与 raycast 在深色场景观察到的「饱和语义色配透明度软底」（CASE-2026-08-16 batch1）是同型结构。

### 1.2 文本灰阶 = 黑 + 透明度，边框灰阶 = 实色两级

正文 `#000000e0`（88% 黑）、次级 `#000000a6`（65%），禁用/说明用 `rgba(0,0,0,.45/.25)` 阶梯（0.88×77 次、0.45×38 次）——文本色不定义具体灰，用「黑 + 透明度」生成，保证与任意底色可组合。边框才是实色：`#d9d9d9`（主）/ `#f0f0f0`（次）两级。

### 1.3 表面双层：容器白 + 布局灰

`colorBgContainer #fff` 与 `colorBgLayout #f5f5f5` 分离——内容面与页面框架面分层，工作台产品经典双层结构。

### 1.4 密度参数族（B 端中密度）

基准字号 `14px`，标题五级 `38/30/24/20/16`；控件高度 `32px`（sm `24px`）两档；圆角 `6px` 基准（lg `8px`，组件内多数引用 var 而非裸值）；线宽 `1px`。间距 151 个 px 值中 64% 为 4 的倍数、40% 为 8 的倍数——4/8 刻度为主但不严格。

### 1.5 浮层三层低透明度阴影（单层重阴影的反面）

`box-shadow: 0 6px 16px 0 rgba(0,0,0,.08), 0 3px 6px -4px rgba(0,0,0,.12), 0 9px 28px 8px rgba(0,0,0,.05)`——三层叠加、每层低透明度，浮起感柔和。

### 1.6 动效克制

`motionDurationFast .1s` / `motionDurationMid .2s`——微交互统一亚 300ms；长动画（1–4s）仅出现在首页营销区。

### 1.7 令牌架构：seed → 组件派生两级（本案例对 B 端最有参考价值）

7,798 个令牌呈「全局种子（`--ant-font-size`）→ 组件级派生（`--ant-btn-content-font-size-sm` 等）」两层结构；v5 用 CSS-in-JS 把令牌编译进 `@layer antd` 下发。是 `PAT-VIS-101`（设计令牌单点化与多主题切换）在 B 端组件库规模的实证形态。

## 2. 排除记录（观察到了但不建议直接借鉴）

| 配方 | 排除理由 |
|---|---|
| 全量 10 色阶语义色板（magenta `#eb2f96`/`#c41d7f` 等高频出现） | 面向数据可视化场景；普通工作台产品照搬会鼓励彩色滥用，强调色纪律（单主色）优先 |
| 首页 1–4s 营销动效 | 文档站营销属性，工具类产品不适用 |
| AlibabaSans 专有字体 | 品牌资产，许可不随仓级 MIT 覆盖；只记录存在事实，不采纳 |
