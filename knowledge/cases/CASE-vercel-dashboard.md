## 1. 可迁移的观察

### 1.1 近白画布的黑白二重奏

canvas `#ffffff` / soft `#fafafa` / soft-2 `#f5f5f5` 三级浅底，墨色 `#171717` 一档主色，正文 `#4d4d4d`、弱化 `#888888`。**观察**：与候选 D 的浅色直角体系几乎同构（白底、石墨主交互、灰阶三档文本），是 D 最直接的语料参照；底色差只有 3 级且幅度极小，层级主要靠墨色与细线。

### 1.2 细线三级 + 唯一彩色链接

hairline `#ebebeb` / strong `#a1a1a1` 两级细线承担全部边界；唯一彩色是链接蓝 `#0070f3`（配 deep `#0761d1` / soft `#d3e5ff` 变体）。**观察**：「无卡片、细线分隔、链接即点缀」的完整浅色方案，与 `CASE-linear-workbench`（深色同纪律）互补成对。

### 1.3 语义色带 soft / deep 变体

error `#ee0000` / error-soft `#f7d4d6` / error-deep `#c50000`，warning 同构三件套。**观察**：语义色不是单值而是「主值 + 浅底 + 深值」小家族——提示、背景、按压态各有其色，比单值语义色更可用；与 `CASE-antd-v5-tokens` 的「主色四件套 + 同色相软底」同型。

### 1.4 技术标签用等宽字体

caption-mono / code 用 Geist Mono：技术 ID、状态标签、代码语境统一等宽小字。**观察**：工作台的订单号 / 状态 / 引用标识用等宽字体是低成本的专业感来源；对应到客服场景，会话 ID、Mock 标识、依据引用可考虑同法。

### 1.5 输入与按钮规格

表单输入高 40px、6px 圆角、hairline 边框；导航 CTA 高 28px、6px 圆角（营销大按钮另用胶囊）。**观察**：功能场景控件圆角收敛在 2-6px，与胶囊营销按钮明确分层——支持「按钮 / 输入圆角分级」观察（`CASE-slack-messaging`）且给出功能场景的下限值。
