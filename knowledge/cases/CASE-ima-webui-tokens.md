- **来源**：`SRC-PROD-001`（https://ima.qq.com，链接核验 2026-08-31 可访问，标题「ima - 腾讯AI知识管家」）

- **状态**：candidate（2026-08-31 登记，待评审）
- **观察输入**：Plan A extract-tokens.py 静态抽取（访问日期 2026-08-31；HTML 49756B + 2 份 CSS：ui-vendor 490856B、app 422414B，均经 static.ima.qq.com /ima/assets/chat/assets/ 路径，即 Web 端聊天界面资产；另用 curl 核实 app CSS 内两套 brand 定义字节序）
- **观察维度**：配色与表面分级 / 字阶 / 圆角与间距节奏 / 组件尺寸刻度
- **同源关联**：与 `CASE-ima-knowledge-base`（2026-08-16，交互 / IA 向，二手需求材料输入）互补——彼条记行为结构，本条记视觉配方，同挂 SRC-PROD-001。

## 1. 观察到的配方

### 1.1 双层令牌架构：TDesign 供应商底盘 + ima 自有薄主题层

Web 端首屏加载的两份 CSS 里存在两套命名体系：`--td-*` 前缀的 TDesign 组件体系全套令牌（字号 / 行高 / 组件尺寸 / 间距 / 圆角 / 断点，共 1358 条自定义属性），叠加一层无前缀的 ima 自有令牌（`--brand_color_green_primary`、`--color-*` 系列）。组件级尺寸与间距直接消费 TDesign 刻度（`--td-comp-size-xs`=24px → `xxxxl`=72px 的控件高度阶；margin / padding 走 `--td-size-N` 2px 基准刻度 2/4/6/8/12/16…72），品牌与场景色则走自有令牌。**观察**：成熟开源组件库当底盘、自有层只管品牌与场景语义——主题改造的工程量集中在薄层，而非重写组件刻度。

### 1.2 单色底盘：灰阶接管品牌梯度，绿色只做低频强调

app CSS 内 `--td-brand-color-1…10` 有两套定义：TDesign 默认蓝系（#f2f3ff→#001a57，6 号位 #366ef4）在文件约 31.7KB 处，纯灰阶系（#f3f3f3→#000000，6 号位 #717171；dark 向反向 #303030→#f3f3f3）在约 82.9KB 处，同选择器同特异性，按层叠规则推断**灰阶系生效**（运行时复核见 §3）。调色板频次佐证：top40 高频色几乎全为中性（rgba(255,255,255,.22) ×38、#ffffff ×36、#c5c5c5 ×20、rgba(0,0,0,.25) ×16…），品牌绿仅 rgba(17,207,112,1) ×5。自有层声明品牌主绿 rgba(7,157,85,1)（#079D55）+ 软底 rgba(7,157,85,.06)。**观察**：界面纪律是「灰阶承担全部结构层级，品牌绿刻意压低出现频次，只出现在品牌点与正向状态」——克制的一色强调，而非彩色主题。

### 1.3 半透明叠加体系与多机制双主题

颜色大量使用带 alpha 的白 / 黑而非实色灰：白系 .04/.08/.1/.2/.22/.35/.7/.9，黑系 .05/.08/.15/.2/.25/.4/.6/.9，另有遮罩 #00000066 与渐变遮罩令牌（`--color-gradient-1/2/3`，透明→白）。双主题令牌齐备（`theme-mode=light` 372 处 / `dark` 299 处声明），且并存五种机制：`theme-mode` 属性、`html[ima-theme=dark]`、`.disable-dark` 类、`prefers-color-scheme` 媒体查询、`[data-ima-shadow-root]`（shadow DOM 边界穿透）。**观察**：同一层半透明白 / 黑叠加可同时适配多种底色——比逐主题配实色 token 更适合悬浮层 / 玻璃感表面；但五机制并存反映多端（小程序 / 移动 / 嵌入）兼容包袱（见排除记录）。

### 1.4 紧凑字阶：14px 主战场，行高统一 +8

TDesign 完整字阶在库（12/14/16/20/24/28/36/48/64，display 64/72 顶格），行高严格 +8：12→20、14→22、16→24、20→28、24→32、28→36、36→44、48→56、64→72。实际使用频次高度下沉：14px ×257、12px ×89、16px ×31、18px ×31、10px ×21——主力 14/12，典型高密度工具型 UI。主字体栈 PingFang SC → Microsoft YaHei → Arial（`--td-font-family`）；栈中另见 AlimamaFangYuanTi（阿里妈妈方体，免费可商用）与代码场景 Source Code Pro 优先栈。

### 1.5 圆角：组件库默认被应用层整体改档

TDesign 默认 `--td-radius-default`=3px，但直接引用仅 1 次；实际频次 8px ×109、4px ×57、12px ×27、16px ×24、6px ×23，另有 50% ×31（圆形头像 / 徽标）与 999px（胶囊）。**观察**：供应商默认值存在 ≠ 生效——应用层把圆角整体上调到 8px 主档、大容器 12/16，视觉基调比 TDesign 默认更柔和。

### 1.6 间距：强 4/8 节奏

纯 px 间距值 983 个，其中 4 的倍数 753（76.6%）、8 的倍数 455（46.3%）；高频值 0/2/4/8/12/16/24/32，高频组合如 padding:8px ×36、0 8px ×34、gap:4px ×25、margin-top:16px ×22、10px 12px ×21（10px 类微调值存在但非主干）。令牌层以 2px 为基准刻度（`--td-size-1`=2 … `--td-size-16`=72）。**观察**：4/8 双层节奏（细粒度 4、粗结构 8）+ 令牌刻度兜底，是可迁移性最强的部分。

### 1.7 动效：环境动画主导，微交互节奏未入静态数据

时长频次 2s ×127、3s ×22、28s ×11、24s ×6、1s ×3、1.4s/1.5s ×2。**观察**：长时长占绝对多数，指向加载 / 呼吸 / 循环类环境动画；静态 CSS 中未见 0.1–0.3s 级微交互高频值（可能在 JS 运行时注入或未被抽取，见 §3）——本条不构成对 ima 微交互节奏的判断。

## 2. 排除记录（观察到了但不建议直接借鉴）

| 配方 | 排除理由 |
|---|---|
| TDesign 默认蓝系梯度（#366ef4 系） | 被灰阶覆盖，疑似供应商默认残留；不应把「蓝品牌色」当作 ima 的设计决策引用 |
| 五机制并存的暗色切换（theme-mode / ima-theme / disable-dark / prefers-color-scheme / shadow-root） | 多端兼容的历史包袱；新项目应选一种机制做透，照抄复杂度只会引入状态不一致风险 |
| 长时长动效（2s+）作交互参考 | 作用对象不明（多为环境 / 循环动画语境），不构成微交互节奏证据 |
| 9/10/11px 微调字号与 10px 间距微调值 | 局部补偿值而非刻度主干，成规模引用会破坏字阶 / 间距节奏 |
