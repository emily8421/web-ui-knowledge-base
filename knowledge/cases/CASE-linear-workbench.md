## 1. 可迁移的观察

### 1.1 表面台阶承担层级，无阴影

canvas 之上设四级表面（surface-1 `#0f1011` → surface-4 `#191a1b`），配三级细线（hairline `#23252a` / strong / tertiary）；层级 = 「表面升一级 + 1px 细线」，语料明确拒绝投影，且禁止跳级。**观察**：直角细线工作台的层级机制范本——浅色场景同构（白底 + 灰底 + 细线），与 `CASE-vercel-dashboard` 互证。

### 1.2 单强调色的极端纪律

唯一彩色是薰衣草蓝 `#5e6ad2`，语料限定只用于品牌标、主 CTA、焦点环、链接强调四处，明令「不得作区块背景 / 卡片填充、不得引入第二种彩色」。**观察**：与 `CASE-intercom-cs-workbench`（炭黑 + Fin 橙）、`CASE-slack-messaging`（单主色 + 链接蓝）三案同向，「中性底盘 + 单强调色」候选模式的又一独立证据（第 4 案）。

### 1.3 紧凑控件规格

按钮统一 8×14px 内边距、8px 圆角；输入 8×12px；触控按钮 ≥40px、触屏输入 ≥44px。**观察**：专业工具的控件比营销页紧凑得多，圆角克制（8px 上限用于按钮，卡片 12px，禁胶囊 CTA）。

### 1.4 「不用纯黑」的底色细节

深色底取 `#010102`（带微蓝）而非 `#000000`，语料明令禁 true black。**观察**：底色留一点色相倾向是高级感的常见微操作，浅色场景对应物是「白底用 #ffffff、灰底带极浅色温」而非纯灰。
